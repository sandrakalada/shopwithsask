Nok Courier shipment – prompt for the Claude Chrome extension

How it works: in the inventory app, open the order and tap "Create shipment". Nok Courier opens in a new tab and the order details are copied. In the Nok tab, open the Claude extension and paste the prompt below, then paste the copied details under it.

---

You are on the Nok Courier portal (https://ots.nokcourier.com). Create one shipment for the order details at the end of this message.

1. If the login page is showing, stop and ask me to sign in. Never type, save or ask for my password. Continue once I am signed in.
2. Pickup first: if there is no open pickup for today, create one in Pickups. If today's pickup is already open, use it. Only one pickup request per day for all shipments.
3. Go to Shipments, then Create Shipment.
4. Fill in:
   - Receiver name, phone, address and city/area exactly as given (pick the closest city/zone in Nok's list; if unsure, ask me).
   - Product Type and Lines (the items from "Contents").
   - COD = "Cash to collect" (agreed product price + agreed delivery fee; this is what the Nok courier collects). If it is 0, the order is already paid.
   - Number of pieces = "Pieces".
   - Description/contents = "Contents".
   - Reference/order number = the order number without # (for example 1410; it prints as "REF: 1410").
   - Description = items like "Heart-Shaped Playing Card Handbag x1". Weight 1 kg unless told otherwise.
   - Notes = "Note", if any.
5. Before you submit, show me a short summary of what you filled in and wait for my OK.
6. Submit, then click "Add to opened Pickup Request" so it joins today's pickup request (the same one for every order today).
7. Find the new shipment card (it shows the AWB number, city, receiver, address, description, phone, COD, weight, with Details / Print AWB / Track buttons). Click "Print AWB" to open the AWB PDF (the shipping label with barcode, Ship To, COD and REF). Check that the name, address, phone, COD and REF match the order.
8. Download/save the AWB PDF and tell me the AWB number (e.g. 590064526610). I add the PDF in the inventory app (shipment page, "Add Nok AWB"); it fills the tracking number and becomes the label.
9. Do not create duplicate shipments: if one with the same order number already exists, tell me instead.
