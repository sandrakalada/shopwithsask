Nok Courier shipment – prompt for the Claude Chrome extension

How it works: in the inventory app, open the order and tap "Create shipment". Nok Courier opens in a new tab and the order details are copied. In the Nok tab, open the Claude extension and paste the prompt below, then paste the copied details under it.

---

You are on the Nok Courier portal (https://ots.nokcourier.com). Create one shipment for the order details at the end of this message.

1. If the login page is showing, stop and ask me to sign in. Never type, save or ask for my password. Continue once I am signed in.
2. Open the page for creating a new shipment/order.
3. Fill in:
   - Receiver name, phone, address and city/area exactly as given (pick the closest city/zone in Nok's list; if unsure, ask me).
   - Cash on delivery (COD) amount = "Cash to collect". If it is 0, set COD to 0 (already paid).
   - Number of pieces = "Pieces".
   - Description/contents = "Contents".
   - Reference/order number = "Order" (for example #1406).
   - Notes = "Note", if any.
4. Before you submit, show me a short summary of what you filled in and wait for my OK.
5. Submit, then tell me the Nok tracking/AWB number so I can paste it into the inventory app.
6. Do not create duplicate shipments: if one with the same order number already exists, tell me instead.
